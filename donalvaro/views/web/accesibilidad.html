Declaración de accesibilidad

Última actualización: junio de 2026

Compromiso con la accesibilidad

Don Álvaro Digital tiene el compromiso de facilitar el acceso a su plataforma al mayor número posible de personas, independientemente de sus capacidades, circunstancias personales o medios técnicos utilizados.

El objetivo es que los contenidos y funcionalidades de la plataforma puedan utilizarse de forma clara, sencilla y compatible con distintos dispositivos y tecnologías de apoyo.

Situación de cumplimiento

Este sitio web se ha desarrollado siguiendo criterios de accesibilidad web y tomando como referencia las Pautas de Accesibilidad para el Contenido Web WCAG 2.1.

La plataforma se encuentra en proceso de revisión y mejora continua para alcanzar el mayor grado posible de conformidad con dichas pautas.

Medidas adoptadas

Entre las medidas aplicadas para mejorar la accesibilidad se incluyen:

  • Uso de una estructura HTML semántica.
  • Diseño adaptable a diferentes tamaños de pantalla.
  • Contraste adecuado entre texto y fondo.
  • Uso de textos descriptivos en enlaces y botones.
  • Navegación clara y consistente.
  • Compatibilidad con navegación mediante teclado.
  • Formularios con etiquetas asociadas a sus campos.

Contenido no accesible

Aunque se trabaja para que toda la plataforma sea accesible, podrían existir contenidos o funcionalidades que todavía no cumplan completamente todos los criterios de accesibilidad.

En caso de detectar alguna dificultad de acceso o uso, puede comunicarlo para que pueda ser revisado y corregido.

Comunicación de incidencias

Si encuentra barreras de accesibilidad en esta plataforma, puede comunicarlo a través de los medios de contacto habilitados por el Ayuntamiento de Don Álvaro o mediante la sección de contacto de esta web.

En la comunicación puede indicar la página o funcionalidad afectada, el problema detectado y, si lo considera oportuno, el dispositivo, navegador o tecnología de apoyo utilizada.

Mejora continua

La accesibilidad de Don Álvaro Digital se revisará periódicamente para corregir posibles incidencias y adaptar la plataforma a nuevas necesidades, requisitos técnicos o cambios normativos.

Esta declaración de accesibilidad podrá actualizarse en función de mejoras técnicas, cambios normativos o nuevas evaluaciones realizadas sobre la plataforma.
