Funcionamiento

Cómo funciona

Una plataforma sencilla para gestionar reservas y accesos de forma segura.

1
Registro

El usuario crea su cuenta mediante correo electrónico.

2
Reserva

Se seleccionan las fechas y se comprueba la disponibilidad.

3
Acceso

El sistema genera automáticamente el PIN o código QR de acceso.

4
Gestión

Usuarios y administradores pueden consultar reservas e históricos.
